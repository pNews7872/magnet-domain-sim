# 자석을 가까이 대면 자구는 어떻게 변할까

네오디뮤 자석을 5 cm 정육면체(철, 강철, 코발트, 니켈, 퍼멀로이, 자철석, 상자성·반자성 금속)에 가까이 가져가면서, 정육면체의 자화와 나노 입자 속 자구가 어떻게 바뀌는지 보는 3D 시뮬레이션이에요.

**바로 열기:** https://pnews7872.github.io/magnet-domain-sim/

## 파일 구성

| 파일 | 내용 |
|---|---|
| index.html | 화면 구조와 설명 |
| style.css | 색, 배치, 모바일 대응 |
| physics.js | 자석 자기장 해석해, Newell 반자장 텐서, FFT, 결함·입자 모양, LLG 솔버(CPU) |
| hysteresis.js | Jiles–Atherton 이력 모형, 5 cm 정육면체 블록 정자기 해석기 |
| macro-engine.js | 같은 자속 기준 자기력선, 힘 계산, 자기력선 추적 |
| gpu.js | WebGPU 마이크로마그네틱 솔버 (CPU와 같은 식, 단정밀도) |
| app.js | 3D 화면, 조작, 계산 엔진 연결, GPU 자체 검사, 자구·흐름선 그리기 |

빌드 과정 없이 브라우저에서 바로 돌아가요.

## 무엇을 계산하고 보여주나

- **자석의 자기장**: 균일하게 자화된 직육면체 자석(20×20×10 mm, 1.3 T)의 해석해.
- **자기력선**: 자석 단면을 실제 자속이 같은 36칸으로 나눠 시작하므로 선 밀도가 세기에 비례해요. 철을 지나는 선은 주황색.
- **5 cm 정육면체**: 8³ 블록 정자기 계산과 측정값에 맞춘 Jiles–Atherton 이력 모형.
- **나노 입자**: 실제 물성값으로 LLG 방정식. 교환, 결정 이방성(K₁, K₂), 반자장, 외부 자기장, 열 요동, 결함 다섯 종류. 입자 모양(정육면체, 구, 얇은 판, 원판, 막대).
- **자구 보기와 자화 흐름선**: 같은 쉬운 방향으로 정렬된 영역을 3D 덩어리로, 자화가 이어지는 방향을 선과 흐르는 점으로 보여줘요.
- **온도**: Kuz'min 식(포화자화), 퀴리–바이스 법칙(퀴리 온도 위).
- **GPU**: 크롬에서 WebGPU를 쓸 수 있으면 64³ 격자까지 계산하고, 자구도 GPU가 매 화면 그려요. 열 때마다 CPU와 결과를 비교해 일치할 때만 써요.

근사와 가정, 측정값 대비 오차는 페이지 아래 설명에 자세히 있어요. 계산을 보는 탭이 화면에 보이지 않으면 브라우저가 계산을 크게 늦춰요.
