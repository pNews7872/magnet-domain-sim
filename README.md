# 자석을 가까이 대면 자구는 어떻게 변할까

네오디뮴 자석을 5 cm 정육면체(철, 강철, 코발트, 니켈, 퍼멀로이, 자철석, 상자성·반자성 금속)에 가까이 가져가면서, 정육면체의 자화와 나노 크기 입자 속 자구가 어떻게 바뀌는지 보는 3D 시뮬레이션이에요.

**바로 열기:** https://pnews7872.github.io/magnet-domain-sim/

## 무엇을 계산하나

- **자석의 자기장**: 균일하게 자화된 직육면체 자석(20×20×10 mm, 1.3 T)의 해석해. 정확한 계산이에요.
- **5 cm 정육면체의 반응**: 8³ 블록으로 나눈 정자기 계산(Newell 텐서, FFT)과 Jiles–Atherton 이력 모형. 이력 모형 계수는 측정된 이력 곡선 값(보자력, 잔류자속밀도, 최대 투자율)에 맞춰 구했고, 측정값 대비 오차는 페이지 안의 표에 공개되어 있어요.
- **나노 정육면체**: 실제 물성값으로 Landau–Lifshitz–Gilbert 방정식을 풀어요. 교환, 결정 이방성(K₁, K₂), 반자장, 외부 자기장, 열 요동, 결함 다섯 종류(비자성 개재물, 결정립 경계, 다결정, 단단한 석출물, 내부 응력)를 포함해요.
- **온도**: Kuz'min 식으로 포화자화의 온도 변화를, 퀴리 온도 위에서는 퀴리–바이스 법칙으로 상자성 자화율을 계산해요.

## GPU 계산

크롬에서 WebGPU를 쓸 수 있으면 나노 정육면체 계산을 GPU로 해서 64³ 격자까지 돌릴 수 있어요. 페이지를 열 때마다 같은 상태를 CPU와 GPU로 계산해 비교하고, 결과가 일치할 때만 GPU를 써요. 일치하지 않거나 GPU가 없으면 CPU로 계산해요.

## 한계

근사와 가정은 페이지 아래 "무엇이 정확한 계산이고 무엇이 근사인가"와 "온도와 결함은 어떻게 넣었나"에 자세히 적혀 있어요. 화면 속 나노 정육면체는 5 cm 정육면체를 확대한 모습이 아니라, 탐침 위치에 놓인 같은 재료의 독립된 나노 입자예요.
